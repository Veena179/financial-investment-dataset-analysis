# financial-investment-dataset-analysis
This project was completed during my **Business Analytics Internship at Cognifyz Technologies**.  
The objective of this project is to analyze investor behavior, investment preferences, and savings objectives using data analytics techniques.

## Project Objective
The goal of this analysis is to understand patterns in investment decisions and identify the most preferred investment avenues using statistical analysis and data visualization.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Microsoft Excel
- Jupyter Notebook

## Dataset
The dataset contains information about investor demographics, investment preferences, savings objectives, investment duration, and expectations from investments.

## Tasks Performed
- Loaded and explored the dataset using Python.
- Performed descriptive statistics analysis for numerical variables.
- Visualized gender distribution using charts.
- Identified the most preferred investment avenues.
- Analyzed reasons for investment decisions.
- Studied savings objectives of investors.
- Examined common sources of investment information.
- Calculated average investment duration.
- Summarized expectations from investments.
- Conducted correlation analysis between investment factors.

## Key Insights
- Identified the most popular investment options among participants.
- Observed patterns in savings goals and financial planning.
- Analyzed investor expectations and behavior.
- Explored relationships between investment duration, age, and returns.
